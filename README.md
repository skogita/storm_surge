# storm_surge
Storm surge simulator — typhoon wind and pressure, tide, Earth's rotation, wind waves and wave groups; global tide and nested grids — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XV / 高潮のシミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XV』の設計書とコード
